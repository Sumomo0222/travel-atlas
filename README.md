# 山河手帖 · 个人旅行地图

一座复古纸图风格的个人旅行手账网站：把每一次出发钉在同一张地图上——**路线、照片，与碎片日记**。

## 运行

纯静态站点，无构建步骤，需要联网（加载字体、Leaflet 与地图瓦片）：

```bash
cd travel-atlas
python3 -m http.server 4173
# 打开 http://127.0.0.1:4173
```

或任何静态服务器（`npx serve` 等）。

## 功能

- **可缩放地图**：Esri 地形图瓦片 + 纸感做旧滤镜，朱红图钉，悬停显示城市 / 情绪 / 日期。
- **点击地点展开记忆**：明信片式抽屉卡——邮戳、情绪印章、主题标签、手写批注、拍立得照片、时间戳碎片日记；支持 上一段 / 下一段（也可用键盘 ← →，Esc 关闭）。
- **筛选**：按 年份 / 情绪 / 主题 组合筛选，不相关的图钉与时间轴刻度自动灰化；显示"n / N 段记忆正被点亮"。
- **时间轴**：底部年份卷轴，按年代排列所有记忆，点击直接飞往该城并展开卡片。
- **回忆路线**：一键（或开场自动）把当前筛选的记忆按时间顺序连成手绘风虚线航线，航点编号随绘制逐步显现；路线面板给出诗意总结、城市 / 总里程 / 跨越年头 / 碎片统计与全程站次列表。
- **放映回忆**：自动巡游——依次飞往每一站，播放站点邮戳签；随时停止。
- **编辑入口**：见下节「添加与编辑旅行记忆」。
- **深链接**：`?year=2023`、`?mood=治愈`、`?theme=海岛与海`、`?open=iceland-2023`、`?edit=new`、`?edit=<id>`、`?tour=1`、`?noroute=1`。

## 添加与编辑旅行记忆

页面上有两处编辑入口，无需改代码：

1. **左栏「＋ 新的记忆」**——打开编辑器，填城市 / 日期 / 情绪 / 主题 / 标题 / 批注，逐条添加碎片日记（时间 + 一句话）和照片（picsum seed 或图片 URL）。
2. **每张记忆卡底部「✎ 编辑此页 / ✂ 撕掉这一页」**——修改或删除任何一页，内置示例也能改。

编辑器里可点「⌖ 在地图上拾取坐标」直接在地图上选点。保存后：图钉、时间轴、筛选栏、统计与回忆路线立即重建，并自动飞往新地点。

**数据保存在浏览器 localStorage**（键 `atlas.data.v1`），刷新不丢；左栏提供：

- **导出**——下载 `山河手帖-备份.json`（含新增 / 修改 / 删除记录）；
- **导入**——载入备份文件，整册恢复；
- **恢复示例**——清空本地改动，回到内置 16 段示例。

注意：数据只存在当前浏览器里，换设备或换浏览器请先「导出」。若导入的记忆使用了自定义情绪 / 主题词，筛选栏会自动出现对应胶囊。

## 编辑自己的旅行记忆（data.js / 页面两种方式）

除了在页面上直接编辑（见上节，存 localStorage），也可以把内容直接写进 `data.js`，每条记忆一个对象：

```js
{
  id: 'kyoto-2019',
  city: '京都', latin: 'KYOTO', country: '日本',
  coord: [35.0116, 135.7681],       // 纬度, 经度
  date: '2019-04-06',               // 用于排序 / 年份 / 邮戳
  mood: '治愈',                     // 情绪（任意词，会在筛选栏自动出现）
  theme: '人文古迹',                 // 主题，需在 THEME_ORDER 中登记以获得小图标
  title: '哲学之道的樱花，落得很慢',
  note: '第一次一个人出门',           // 手写批注，可省略
  zoom: 6,                          // 点击时的地图缩放级别
  photos: [{ seed, w, h, cap }],    // seed 决定占位照片；换成自己的图片 URL 亦可
  fragments: [{ time: '05:50', text: '……' }],
  labelSide: 'l' | 't' | 'b',       // 可选：密集区域名称标签的朝向
}
```

筛选栏的年份自动取自数据；情绪顺序在 `MOODS`，主题图标在 `ICONS`。

## 文件结构

```
travel-atlas/
├── index.html   # 页面骨架
├── style.css    # 复古手账视觉（陈纸 / 墨线 / 朱印 / 暗角 / 纸纹）
├── data.js      # 16 段示例记忆 + 情绪 / 主题 / 图标元数据
└── app.js       # 地图、筛选、时间轴、记忆卡、航线动画、自动放映
```

## 技术说明

- Leaflet 1.9（CDN）+ Esri World Topo 瓦片（CSS sepia 做旧）。
- 字体：Fraunces（西文展示）、Noto Serif SC（正文）、Ma Shan Zheng（手写批注）、IBM Plex Mono（数据标签）。
- 照片为 picsum.photos 占位图，加载失败时回退为内联 SVG 占位卡。
- 无框架、无构建；`prefers-reduced-motion` 下自动关闭动画。
